# legacy/

`index.html` di folder ini adalah **arsip** versi satu-file sebelum refactor ke
Vue 3 + Vite + TypeScript. File ini tidak lagi dipakai, tidak ikut di-build, dan
aset gambarnya sudah dipindah ke `public/` sehingga pratinjaunya tidak lengkap.

Untuk membandingkan perilaku lama vs baru, gunakan git history atau worktree:

```bash
git worktree add ../FingerCarousel-baseline <commit-lama>
```
